# Minimal academic website

Static HTML/CSS. No JavaScript, frameworks, build step, or external assets.

## Customize

1. Replace `Your Name`, `University Name`, and the sample biography and teaching/research details in the three HTML files.
2. Replace `your.email@university.edu` with your email address.
3. Put your CV at `cv.pdf` in this folder, or remove the CV link until it is ready. **No CV is included in this starter package.**
4. Add research PDFs in a `papers/` directory if desired.

## Cloudflare Pages

- For GitHub integration, push these site files to a repository and connect it to Cloudflare Pages.
- In the Pages setup, select no framework; leave the build command empty. Set the output directory to the repository root (`.`) if your files are at the root.
- Alternatively, upload the site folder using Direct Upload.

Open `index.html` in a browser for a basic local preview. All navigation is relative so it works on Pages and locally.
